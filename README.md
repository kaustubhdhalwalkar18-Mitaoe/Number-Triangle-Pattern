# Number-Triangle-Pattern
🔢 Number Right-Angled Triangle Pattern in Python

This project is a simple Python program that prints a right-angled triangle pattern of numbers. Each row contains numbers starting from 1 up to the current row number.

The program demonstrates how nested loops can be used to generate structured numeric patterns.

📌 Features

Accepts number of rows as input

Prints a number-based right-angled triangle

Uses nested loops for pattern generation

Includes input validation

Beginner-friendly and easy to understand
